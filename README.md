# Distributed Systems Practical Labs

Welcome to the Distributed Systems laboratory.

Each laboratory demonstrates a distributed-systems
concept using a small working application.

## Requirements

- Git
- Docker Desktop
- Web browser

## Getting Started

Clone this repository:

git clone https://github.com/yourname/distributed-systems-labs.git

Enter the first lab:

cd distributed-systems-labs/lab-01-client-server

Start the application:

docker compose up

Open:

http://localhost:8000
